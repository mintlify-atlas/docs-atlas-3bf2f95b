---
title: "Register"
description: "POST /api/v1/auth/register — Create a new user account."
---

## Endpoint

```
POST https://code-security-platform.onrender.com/api/v1/auth/register
```

No authentication required.

<Info>
  A first API key is automatically generated when you register. The response also includes a JWT access token so you can start making authenticated requests immediately.
</Info>

## Request body

<ParamField body="email" type="string" required>
  The email address for the new account. Must be unique across the platform.
</ParamField>

<ParamField body="password" type="string" required>
  The password for the new account.
</ParamField>

## Response

### 201 — Account created

Returns a JWT access token and the newly created user object.

<ResponseField name="access_token" type="string" required>
  JWT token for authenticating subsequent requests. Pass this in the `Authorization: Bearer <token>` header.
</ResponseField>

<ResponseField name="token_type" type="string" required>
  Always `"bearer"`.
</ResponseField>

<ResponseField name="user" type="object" required>
  <Expandable title="properties">
    <ResponseField name="id" type="string" required>
      Unique user identifier (UUID).
    </ResponseField>
    <ResponseField name="email" type="string" required>
      The registered email address.
    </ResponseField>
    <ResponseField name="created_at" type="string" required>
      ISO 8601 timestamp of when the account was created.
    </ResponseField>
  </Expandable>
</ResponseField>

### 400 — Email already registered

Returned when an account with the given email already exists.

### 422 — Validation error

Returned when required fields are missing or malformed.

## Example

<RequestExample>

```bash cURL
curl --request POST \
  --url https://code-security-platform.onrender.com/api/v1/auth/register \
  --header 'Content-Type: application/json' \
  --data '{
    "email": "user@example.com",
    "password": "yourpassword"
  }'
```

</RequestExample>
