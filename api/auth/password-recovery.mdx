---
title: "Password Recovery"
description: "Request a password reset link and reset your password using a token."
---

Password recovery is a two-step process: first request a reset email, then submit the token from that email along with your new password.

No authentication required for either step.

---

## Step 1 — Request reset email

### Endpoint

```
POST https://code-security-platform.onrender.com/api/v1/auth/request-password-recovery
```

### Request body

<ParamField body="email" type="string" required>
  The email address associated with your account.
</ParamField>

### Response

### 200 — Request received

Returns a generic success message regardless of whether the email is registered. This prevents email enumeration.

<ResponseField name="detail" type="string">
  A message indicating the request was received.
</ResponseField>

### Example

<RequestExample>

```bash cURL
curl --request POST \
  --url https://code-security-platform.onrender.com/api/v1/auth/request-password-recovery \
  --header 'Content-Type: application/json' \
  --data '{
    "email": "user@example.com"
  }'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "detail": "If your email is registered, you will receive a password recovery link shortly."
}
```

</ResponseExample>

---

## Step 2 — Reset password

### Endpoint

```
POST https://code-security-platform.onrender.com/api/v1/auth/reset-password
```

### Request body

<ParamField body="token" type="string" required>
  The password reset token received in the recovery email.
</ParamField>

<ParamField body="new_password" type="string" required>
  The new password to set for the account.
</ParamField>

### Response

### 200 — Password reset

<ResponseField name="detail" type="string">
  Confirmation that the password was successfully updated.
</ResponseField>

### 400 — Invalid or expired token

Returned when the token is missing, malformed, or has expired.

### 404 — User not found

Returned when the email encoded in the token does not match any account.

### Example

<RequestExample>

```bash cURL
curl --request POST \
  --url https://code-security-platform.onrender.com/api/v1/auth/reset-password \
  --header 'Content-Type: application/json' \
  --data '{
    "token": "<RESET_TOKEN>",
    "new_password": "newsecurepassword"
  }'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "detail": "Password has been successfully reset."
}
```

```json 400
{
  "detail": "Invalid or expired password reset token."
}
```

```json 404
{
  "detail": "User not found."
}
```

</ResponseExample>
