## Endpoints

| Method | Endpoint | Input |
|--------|----------|-------|
| `POST` | `/api/v1/scans` | JSON body — remote repository URL |
| `POST` | `/api/v1/scans/local` | Multipart form — local `.zip` file |

Authentication required. Each scan creation consumes 1 scan credit from your monthly quota.

<Warning>
  If your quota is exhausted, the API returns `403`. Check your current usage at `GET /api/v1/user/usage`.
</Warning>

---

## Remote scan — POST /api/v1/scans

### Request body

<ParamField body="repo_url" type="string" required>
  The URL of the repository to scan (e.g. `https://github.com/owner/repo`).
</ParamField>

<ParamField body="git_token" type="string">
  A personal access token for private repositories. If you have already saved a token via `PUT /api/v1/user/profile`, this field is optional.
</ParamField>

---

## Local scan — POST /api/v1/scans/local

Upload a `.zip` archive of a local repository. Only `.zip` files are accepted.

Send the file as `multipart/form-data` with the field name `file`.

---

## Response

### 201 — Scan created

The scan is created immediately and dispatched to the worker queue. The initial `status` will be `"queued"`.

**Status lifecycle:** `queued` → `running` → `completed` or `failed`

<ResponseField name="id" type="string" required>
  Unique scan identifier (UUID).
</ResponseField>

<ResponseField name="user_id" type="string" required>
  UUID of the user who created the scan.
</ResponseField>

<ResponseField name="status" type="string" required>
  Current scan status. One of `queued`, `running`, `completed`, or `failed`.
</ResponseField>

<ResponseField name="repo_url" type="string">
  Repository URL that was scanned. `null` for local scans.
</ResponseField>

<ResponseField name="is_local" type="boolean" required>
  `true` if this was a local file upload scan.
</ResponseField>

<ResponseField name="created_at" type="string" required>
  ISO 8601 timestamp of when the scan was created.
</ResponseField>

<ResponseField name="completed_at" type="string">
  ISO 8601 timestamp of when the scan finished. `null` until completed.
</ResponseField>

<ResponseField name="risk_score" type="number">
  Overall risk score on a 0–10 scale. `null` until the scan completes.
</ResponseField>

<ResponseField name="findings" type="array">
  List of security findings. Empty until the scan completes.
</ResponseField>

### 403 — Quota exceeded

Returned when the monthly scan quota has been exhausted.

### 503 — Worker queue unavailable

Returned when the scan record was created successfully but could not be dispatched to the worker queue. The scan status is set to `"failed"`. Check that `REDIS_URL` is configured correctly.

## Examples

<RequestExample>

```bash Remote repository
curl --request POST \
  --url https://code-security-platform.onrender.com/api/v1/scans \
  --header 'Authorization: Bearer <JWT_TOKEN>' \
  --header 'Content-Type: application/json' \
  --data '{
    "repo_url": "https://github.com/owner/repo"
  }'
```

```bash Private repository
curl --request POST \
  --url https://code-security-platform.onrender.com/api/v1/scans \
  --header 'Authorization: Bearer <JWT_TOKEN>' \
  --header 'Content-Type: application/json' \
  --data '{
    "repo_url": "https://github.com/owner/private-repo",
    "git_token": "ghp_yourpersonalaccesstoken"
  }'
```

```bash Local zip upload
curl --request POST \
  --url https://code-security-platform.onrender.com/api/v1/scans/local \
  --header 'Authorization: Bearer <JWT_TOKEN>' \
  --form 'file=@/path/to/repo.zip'
```

</RequestExample>
