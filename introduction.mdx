## What is Code Security Platform?

Code Security Platform is a cloud-based security vulnerability scanner that analyzes your code repositories using multiple industry-standard scanners running in parallel. When vulnerabilities are found, the platform can automatically generate and submit pull requests with fixes — directly to your GitHub repository.

Whether you're a solo developer or a large engineering team, Code Security Platform helps you ship more secure code faster.

## How it works

<Steps>
  <Step title="Submit a repository">
    Point the platform at any public or private GitHub repository URL, or upload a local workspace as a zip file. The platform clones and prepares the code for analysis.
  </Step>
  <Step title="Scanners run in parallel">
    Seven industry-standard scanners analyze your codebase concurrently — covering static analysis, dependency vulnerabilities, and infrastructure misconfigurations.
  </Step>
  <Step title="Review findings">
    Each finding includes severity (LOW / MEDIUM / HIGH / CRITICAL), the affected file and line number, a description of the vulnerability, and remediation guidance.
  </Step>
  <Step title="Auto-resolve vulnerabilities">
    Trigger automated resolution for any finding or an entire scan. The platform generates a fix and opens a pull request on your repository, ready for review.
  </Step>
</Steps>

## Security scanners

The platform integrates seven scanners to give you comprehensive coverage:

| Scanner | What it catches |
|---|---|
| **Semgrep** | Multi-language static analysis — OWASP Top 10, CWE coverage, 18+ languages |
| **Bandit** | Python-specific issues — hardcoded secrets, SQL injection, insecure crypto |
| **Checkov** | Infrastructure as Code misconfigs — Terraform, Dockerfile, Kubernetes, CloudFormation |
| **pip-audit** | Python dependency CVEs from the PyPI Advisory Database |
| **npm-audit** | Node.js dependency vulnerabilities |
| **Retire.js** | Bundled JavaScript library vulnerabilities (jQuery, etc.) |
| **OSV Scanner** | Multi-language dependency scanning — Go, Rust, JavaScript, and more |
