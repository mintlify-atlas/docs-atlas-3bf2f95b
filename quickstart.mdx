---
title: "Quick Start"
description: "Register for an account, get your API key, and run your first security scan in under 5 minutes."
---

<Steps>
  <Step title="Register">
    Create a new account. On success, the API returns a JWT token and an auto-generated API key.

    ```bash
    curl -X POST https://code-security-platform.onrender.com/api/v1/auth/register \
         -H "Content-Type: application/json" \
         -d '{ "email": "you@example.com", "password": "yourpassword" }'
    ```

    ```json
    {
      "access_token": "<JWT_TOKEN>",
      "token_type": "bearer",
      "user": {
        "id": "...",
        "email": "you@example.com",
        "created_at": "..."
      }
    }
    ```

    Save the `access_token` — you'll use it in the next steps.
  </Step>

  <Step title="Get your API key">
    Your first API key is generated automatically when you register. You can generate additional keys at any time using your JWT token.

    ```bash
    curl -X POST https://code-security-platform.onrender.com/api/v1/user/api-key \
         -H "Authorization: Bearer <JWT_TOKEN>"
    ```

    <Warning>
      The key is returned only once in the response. Store it securely — it cannot be retrieved again.
    </Warning>

    Once you have an API key, you can use it via the `x-api-key` header instead of a Bearer token for all subsequent requests.
  </Step>

  <Step title="Run your first scan">
    Submit a repository URL to start a security scan. The scan runs asynchronously — the response contains a `scan_id` you can use to check progress.

    <CodeGroup>

    ```bash curl
    curl -X POST https://code-security-platform.onrender.com/api/v1/scans \
         -H "Authorization: Bearer <JWT_TOKEN>" \
         -H "Content-Type: application/json" \
         -d '{ "repo_url": "https://github.com/owner/repo" }'
    ```

    ```bash scp-cli
    # Install the CLI
    pip install scp-cli

    # Store your API key locally
    scp-cli auth --key <YOUR_API_KEY>

    # Start a scan
    scp-cli scan https://github.com/owner/repo
    ```

    </CodeGroup>

    The response includes a `scan_id` and an initial `status` of `queued`.

    <Note>
      Starter plan accounts are limited to **2 scans per month**. The API returns `403` when this quota is exceeded.
    </Note>
  </Step>

  <Step title="Review findings">
    Poll the scan endpoint until `status` changes to `completed`, then review the findings list.

    <CodeGroup>

    ```bash curl
    curl https://code-security-platform.onrender.com/api/v1/scans/<SCAN_ID> \
         -H "Authorization: Bearer <JWT_TOKEN>"
    ```

    ```bash scp-cli
    scp-cli status <SCAN_ID>
    ```

    </CodeGroup>

    The response includes a `findings` array with each vulnerability's severity, affected file, line number, description, and remediation guidance. A `risk_score` (0–10) summarizes the overall result.
  </Step>
</Steps>
